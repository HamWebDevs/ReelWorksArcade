# Version 0.3 — reference-led cabinet layout

The supplied photographs were inspected for general construction, density and presentation. They are not included in the repository or APK. No reference branding, characters, logos, artwork, watermark removal or copied paytables were used.

The previous wide-reel/app-card layout is replaced by an original tall cabinet with ribbed side mouldings, chrome glass edges, a sloping lower console, separate button shelf, rubber palm rest and recessed decorative return tray. The tray has no payout function; all credits remain fictional.

Upper glass now comprises a live cash ladder, configured feature route, feature list, bonus-number accumulator, hi-lo number, feature pot, real paytable and themed illustrated bonus panels. These reflect the existing engine, not invented secondary gameplay. Last Orders uses red glass, Empire emerald and Time Shift violet. The central path is a compact serpentine grid showing the actual 24/20/24 stops. Original illustrations are retained as background motifs rather than occupying the main board.

Reels are smaller and located on the lower console with a vertical printed paytable. Actual HOLD/NUDGE controls sit below them. Board decisions occupy the lower portion of the upper glass, leaving the path visible. Individual bonus interactions still use a feature panel. The glass inspector is now a pannable 2× drawing, and the lower console has a separate enlarged reel view.

This is native 2D rendering with drawn cabinet depth, not a 3D model or photograph. Existing 0.2 rules and save schema remain unchanged. The next handset playtest should focus on the smaller full-cabinet controls, zoom scrolling and whether the reference proportions now feel right. Several feature presentations remain shared; this update concentrates on the physical layout.

Validation: Godot 4.7.2 import passed, 745 native UI assertions passed, and all three cabinet/board views plus Darts Dash and Temporal Hi-Lo were rendered and inspected. Full gameplay tests and simulation also run in the Android workflow. No physical Android-device test was available for this layout change.
