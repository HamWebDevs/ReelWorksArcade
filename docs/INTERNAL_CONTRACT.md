# Implementation contract
Project root /workspace/reelworks-arcade. Godot 4.7.2 typed GDScript. 720x1440 portrait logical viewport, canvas_items stretch expand. UI owned by root.

Machine JSON schema: id, name, subtitle, description, jackpot (integer credits), stake (integer), colors {bg,primary,secondary,accent}, special_symbol, symbols (dictionary id -> {label,prize,number,icon}), strips (three arrays of symbol IDs), paytable (dictionary symbol id -> integer triple prize), trail_length, trail_name, trail (array of {label,kind,value}), features (array of bonus IDs), rules (array of strings). See data agent for final fields. ID last_orders, empire_estates, time_shift. Common symbol IDs cherry, lemon, bell, bar, seven, special. Engine evaluates CENTER three equal only, single cherry optional only if documented. Art provides symbol SVGs at assets/symbols/<id>.svg and machine-specific special at assets/symbols/<machine_id>_special.svg. Cabinet artwork SVGs assets/cabinets/<machine_id>.svg, 680x580. Root renders board lamps over art separately.

Core class_name ReelEngine extends RefCounted, signal changed(event: String). Fields config: Dictionary, state: String, credits:int=1000, bank:int=0, positions:Array (3 center indices), held:Array(bool), trail_pos:int, trail_progress:int, nudges:int, feature:Dictionary, message:String, stats:Dictionary, rng:SimRng. Methods configure(machine:Dictionary, seed_value:int=-1), act(action:String, value:int=0)->bool (invalid false), finish_spin()->void, visible_symbols(reel:int)->Array (top,center,bottom dict each with id,number), available_actions()->Array (strings), snapshot()->Dictionary, restore(data:Dictionary)->bool. actions start, hold_0/1/2, nudge_up_0/1/2, nudge_down_0/1/2, collect, cancel, exchange, hi, lo, feature_start, choice_0/1/2, stop, continue, refill, transfer, rewind. START resolves target positions immediately and enters SPINNING; UI animates to them and calls finish_spin. No timers/UI dependency in engine. Signals event spin,stop,win,feature,move,collect,lose,click. Save immediately after accepted transitions, including pending spin.

feature Dictionary UI keys: id, title, prompt, choices:Array(String), number:int, pot:int, stage:int, lives:int, no_lose:bool, cursor:int, zone:String. All optional via get(). UI uses available_actions for buttons. STOP action value is cursor index 0..11, UI deterministic moving cursor every 100ms; documented skill awards depend on this. BONUS handler is owned by core agent unless otherwise arranged. Tests invoke engine directly.

Machine loader class_name MachineLibrary static func all()->Array[Dictionary], static func get_machine(id:String)->Dictionary, static func validate(config:Dictionary)->Array[String], loads built-in + user://machines/*.json. Data agent owns loader, machine files, rules docs. No gameplay mutations outside core. Persistence root-owned scripts/core/save_store.gd. Root project.godot and main UI scenes/scripts. Build agent export_presets.cfg, tools/setup/export scripts, .github/workflows, docs/ANDROID.md. Art agent assets + tools/generate_assets.py. Test agent tests + simulation. All share filesystem: avoid modifying another owner's files without notification.
